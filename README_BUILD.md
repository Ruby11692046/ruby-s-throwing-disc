# Ruby's Throwing Disc（1.21.1 NeoForge）v0.1.11 — ビルド手順

## これは何
1.20.1 Forge 版と同内容の **1.21.1 NeoForge 移植版**（初版）。
ディスク全19種・挙動（貫通／跳ね返り／自動帰還／投げて3秒で強制帰還）・連携14種は共通。
連携は全部ソフト依存で、相手 Mod が無い環境ではそのレシピだけが無効になる。

## ビルド方法（Mac）
前提：**JDK 21**（IntelliJ のログで見た BellSoft の Java 21 が使えるはず）

1. zip を展開し、プロジェクトフォルダをそのまま作業場所に置く
   - ⚠️ パッチ式にファイルを上書きコピーしないこと。更新時はフォルダごと入れ替え
2. ターミナルでフォルダに移動して `./gradlew build`
   - Gradle の JVM が 17 のままだと toolchain で 21 を探しに行く。
     見つからないと言われたら、IntelliJ の Settings → Build Tools → Gradle で
     Gradle JVM を 21 に設定してから実行
3. `build/libs/throwing_disc-0.1.11.jar` ができたら成功
   （BUILD SUCCESSFUL の表示だけで判断せず、jar の実在を確認すること）
4. jar を 1.21.1 NeoForge 環境の mods フォルダへ

## 公式仕様チェック（発表済みの範囲）
公式発表（minecraft.net の game drop 記事・公式X投稿、Minecraft Wiki の引用確認）で
明言されている仕様と、本Modの実装の対応：

- 投げると自動で戻る（エンチャント不要）… 実装済み
- 並んだ敵を複数貫通する … 実装済み
- 帰り道でもダメージとノックバックを与える … 実装済み
- 硬い表面（固体ブロック）で跳ね返り、何度でも跳ね返る。
  跳ね返るたびに遠くへ・速く飛ぶ … 実装済み
- 重力の影響を受けない／いろいろな角度に投げられる … 実装済み
- 飛んでいる間、回転する … 実装済み
- ティアは銅・鉄・金・ダイヤ・ネザライトの5種（木・石は無い）… 実装済み
- メイン／オフハンドどちらからでも投げられ、投げた手に戻る … 実装済み
- スタック不可／チャージなし／クールダウンなし／弾薬なし … 実装済み

公式に数値が出ていないもの（ダメージ・耐久・レシピ・速度・射程・
エンチャント可否）は本Modの仮設計のまま。鉄=7 は Wiki 下書きの値に合わせた。
v0.1.5 では「硬い表面」の解釈を締めた：当たり判定を OUTLINE→COLLIDER に変え、
草・花・松明はすり抜け、固体ブロックでのみ跳ね返るようにした。
