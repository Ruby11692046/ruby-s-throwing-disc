# Ruby's Throwing Disc（1.20.1 Forge）v0.1.8 — ビルド手順

## これは何
2027年第1ドロップで実装予定の新武器「Throwing Disc」の 1.20.1 バックポートMod。
- ディスク全32種：バニラ5種（銅・鉄・金・ダイヤ・ネザライト）＋連携27種
  （Twilight Forest 4 / Aether 3 / Create 3 / Mekanism 4 /
   Deeper and Darker 1 / Cataclysm 6 / Ice and Fire 6）
- 連携は全部ソフト依存。相手Modが入っていない環境では、そのレシピだけが無効になる
- 挙動：投げると直進 → 敵を貫通 → 壁で跳ね返ると射程が伸びて加速 → 自動で手元に戻る

## ビルド方法（Mac）
前提：JDK 17（Spectrum Nouveau のときと同じ環境でOK）

1. zip を展開し、プロジェクトフォルダをそのまま作業場所に置く
   - ⚠️ 前回の事故の教訓：パッチ式にファイルを上書きコピーしないこと。
     更新のときはフォルダごと入れ替える（Gradle の JVM 17 設定だけ、必要なら再設定）
2. ターミナルでフォルダに移動して `./gradlew build`
3. `build/libs/throwing_disc-0.1.8.jar` ができたら成功
   （BUILD SUCCESSFUL の表示だけで判断せず、jar が実在するか確認すること）
4. jar を mods フォルダへ。古い版を入れたことがある場合は古い jar を消してから

## テスト観点（お願い）
- バニラ5種がクラフトできるか（ひし形レシピ／ネザライトは鍛冶台）
- 投げて戻ってくるか、行きと帰りで同じ敵に当たるか
- 壁に当てて跳ね返るか（跳ね返るたびに少し遠くまで飛ぶ）
- オフハンドからも投げられるか
- 連携レシピ：Create が入った環境なら真鍮などのディスクが作れるか。
  入っていない Mod の素材ディスクは作れないのが正常
- インベントリが満杯の状態でキャッチすると足元に落ちるのが仕様

## 公式仕様チェック（発表済みの範囲）
公式発表（minecraft.net の game drop 記事・公式X投稿、Minecraft Wiki の引用確認）で
明言されている仕様と、本Modの実装の対応：

- 投げると自動で戻る（エンチャント不要）… 実装済み
- 並んだ敵を複数貫通する … 実装済み
- 帰り道でもダメージとノックバックを与える … 実装済み
- 硬い表面（固体ブロック）で跳ね返り、何度でも跳ね返る。
  跳ね返るたびに遠くへ・速く飛ぶ … 実装済み
- 重力の影響を受けない／いろいろな角度に投げられる … 実装済み
- 飛んでいる間、回転する … 実装済み
- ティアは銅・鉄・金・ダイヤ・ネザライトの5種（木・石は無い）… 実装済み
- メイン／オフハンドどちらからでも投げられ、投げた手に戻る … 実装済み
- スタック不可／チャージなし／クールダウンなし／弾薬なし … 実装済み

公式に数値が出ていないもの（ダメージ・耐久・レシピ・速度・射程・
エンチャント可否）は本Modの仮設計のまま。鉄=7 は Wiki 下書きの値に合わせた。
v0.1.5 では「硬い表面」の解釈を締めた：当たり判定を OUTLINE→COLLIDER に変え、
草・花・松明はすり抜け、固体ブロックでのみ跳ね返るようにした。

## v0.1.4 での変更
- **投げてから3秒（60tick）で強制的に帰還開始**するようにした。壁で跳ね返り続けて
  射程が伸びても、3秒たったら必ず戻り始める（強制帰還中は帰り足も速くなる）
- 同時に 1.21.1 NeoForge 版も新規作成（別zip）

## v0.1.3 での変更
- ディスクの向きの解釈を修正：縦向き（チャクラム式）をやめ、**平らな円盤が
  投げた視点の入射角のまま傾く**形にした。水平に投げれば水平に飛び、
  上向きに投げればその角度に傾く。跳ね返ると反射後の方向の角度に追従する

## v0.1.2 での変更
- v0.1.1 のコンパイルエラーを修正（JOML の API 差異。向きの計算を回転ベースに書き直し）
- 軌道の粒子トレイルを削除（不要との指示）
- 連携レシピの書き方を変更：条件ラッパー形式 → `forge:conditions` 形式に統一し、
  レシピブックに表示するための解放実績も連携分に追加
  ※相手 Mod が入っていない素材のディスクは、その環境ではレシピが無くて正常
  （例：今のパックでは Twilight Forest / Aether / Mekanism 分は作れない）

## v0.1.1 での変更（ユーザーの実機フィードバック対応）
- Ars Nouveau 連携を削除（ソースジェムディスク廃止）
- 描画のカクカク対策：位置同期を2tick毎→毎tickに変更、軌道に薄い粒子トレイル追加
- 基本射程を 14 → 26 ブロックに延長（跳ね返りボーナスも 8 → 10、真鍮は 16）
- ディスクの見た目の向きが速度に追従するように変更：投げた角度に傾き、
  跳ね返ると進行方向に合わせて向きが変わる（チャクラム式の縦向き飛行）

## 既知の割り切り（v0.1.8）
